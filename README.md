# LunaBot

LunaBot is a lunar rover simulation built with **ROS 2 Jazzy** and **Gazebo Harmonic**.

## Features

- Lunar gravity simulation
- Rover model with wheels
- Lunar terrain
- Rocks and craters
- ROS 2 velocity control
- Odometry

## Package

`lunabot_description`

## Build

```bash
cd ~/lunabot_ws
colcon build
source install/setup.bash
